# 图片框选坐标工具

在浏览器里给本地图片画矩形框，并把框换算成**原图像素**坐标，导出 JSON 或 CSV。页面是单个 `index.html`，不安装软件，打开后也不访问网络。

简要入口见 [使用说明.md](使用说明.md)。操作细节以本文为准。

## 用途与适用场景

适合自己整理检测框、分类框或裁剪区域，需要留下可再处理的坐标文件时使用。一次可以放入多张 JPEG、PNG 或 WebP，每张图可以有多个框。

适合：

- 在本机图片上标矩形，并要原图像素而不是屏幕像素
- 临时标注，标完就导出，不需要账号和服务器
- 把坐标交给自己的脚本，格式只要 `xyxy` 或 `xywh`

不适合：

- 多边形、关键点、画笔掩膜
- 给框填写类别、文字或置信度
- 多人同时标注、云端保存、刷新后继续上次的进度
- 把已导出的 JSON / CSV 再导入回来接着改

## 功能

当前页面实际提供这些能力：

- 用「打开图片」多选文件，或把文件拖进窗口。只接受 JPEG、PNG、WebP（按 MIME 或扩展名 `.jpg` / `.jpeg` / `.png` / `.webp` 判断）。
- 左侧列出已加入的图片。每项显示文件名、解码后的宽高和框数量。点一项切换当前图。
- 在当前图上按住鼠标左键拖动，松开后生成一个框。同一张图可以连续画多个框，按创建顺序编号。
- 右侧列出当前图的框。点一项选中；选中的框在图上用蓝色边显示，未选中的是琥珀色。
- 右侧预览只显示**当前图**的文件名、宽高和框，单位是原图像素。
- 工具栏可以选择 `xyxy` 或 `xywh`。切换只改变预览和导出的写法，不改已经记下的框。
- 导出 `bboxes.json` 或 `bboxes.csv`。导出包含**已加入的每一张图**，包括还没点开、也没有框的图。
- 加入图片后就会在本地读取宽高，不需要先点开该图。正常解码的图片不会以宽高 0 导出；如果某张图解码失败，本次导出取消，并提示文件名。
- 缩放：工具栏 `−` / `+` / `适应` / `1:1`，以及 `Ctrl`（Mac 上为 `Cmd`）加滚轮，以鼠标所在位置为中心缩放。
- 平移：按住空格拖动、按住鼠标中键拖动，或按住 `Alt` 拖动。平移只滚动中间画布，不会因此新增框。
- 放大到 300% 及以上时，图片改为像素化显示，便于对齐边缘。
- 框始终记成原图像素。缩放、平移、切换显示比例都不会改写已有框的数字。
- 删除当前图上选中的框；没有选中框时，删除当前图最后一个框。
- 清空**当前图**的全部框（会先询问）。不影响其他图。
- `←` / `→` 切换上一张 / 下一张。

没有这些能力：导入已有标注、移动或缩放已画好的框、从列表移除某张图、撤销已删除的框、给框命名、自动保存。

## 环境要求

- 一台可以运行桌面浏览器的电脑。页面按桌面窗口设计，没有单独的手机触控界面。
- 建议使用较新的 Chrome、Edge、Firefox 或 Safari。需要浏览器能解码你打开的 JPEG、PNG 或 WebP，并支持本地文件选择和 `blob:` 地址。
- 画框需要鼠标左键拖动，或触控板上等效的主键拖动。中键平移需要鼠标中键。
- 不需要安装 Node.js、Python 或其他运行时，不需要构建，也不需要本地 Web 服务器。
- 打开页面之后可以断网。页面不加载远程脚本、样式、字体或图片。

窗口较窄时，顶栏按钮会换行，左中右三栏会变挤。中间图片仍应留在中间格子里滚动，而不是把左右栏挤出窗口。建议窗口宽度能同时看见三栏（大约 1000 像素以上更从容）。

## 下载与安装

这个工具**不需要安装**。运行时只依赖同目录下的 `index.html` 这一个文件。`README.md` 和 `使用说明.md` 只是说明，不参与运行。可以把 `index.html` 单独复制到另一台电脑使用。

还是要把文件放到本机，浏览器才能打开它。任选一种：

1. 克隆仓库后使用仓库里的文件：
   ```bash
   git clone https://github.com/lianxushi/tools.git
   ```
   文件位于 `tools/bbox-annotator/index.html`。
2. 在 GitHub 仓库页面下载 ZIP，解压后进入 `bbox-annotator` 目录。
3. 只保存 `index.html`：在仓库里打开该文件，使用页面上的 Raw / Download 把内容保存到本机，文件名保持 `index.html`。不要在 GitHub 的网页预览里直接标注，那个页面不会把 HTML 当成本地工具运行。

不需要执行 `npm install`，也不需要配置环境变量。

## 启动

1. 在文件管理器中双击 `bbox-annotator/index.html`。
2. 若双击没有用浏览器打开，可以打开 Chrome、Edge、Firefox 或 Safari，按 `Ctrl+O`（Mac 为 `Cmd+O`）选择这个文件。
3. 也可以把 `index.html` 拖进已经打开的浏览器窗口。

地址栏一般是 `file:///.../bbox-annotator/index.html`。看到标题「图片框选坐标」、左栏「图片列表」和中间的提示文字，就表示已经启动。没有单独的启动命令，也没有需要保持运行的后台进程。

## 操作说明

### 打开图片与多图多框

1. 点左上角「打开图片」，选择一张或多张 JPEG、PNG、WebP。也可以把这些文件拖进窗口，看到「松开以添加图片」后再松开。
2. 新加入的第一张会立刻显示在中间。其余图片出现在左侧列表，宽高会在解码完成后显示为「宽×高」，解码完成前显示「读取尺寸…」。
3. 在图片上按住左键，从一角拖到对角，松开。拖动方向不限，松手后会整理成左上角到右下角。宽或高不足 2 个原图像素的拖动会被忽略。
4. 继续拖动可在同一张图上添加更多框。新框出现在右侧列表底部，并处于选中状态。
5. 点右侧某一项，只改变选中状态，不改变坐标。点「删除选中框」删除它。
6. 点左侧另一张图：当前图的框留在这张图自己的数据里。切换会取消选中、把缩放恢复为「适应」，并把滚动位置回到左上角。再点回来，原来的框还在。
7. `←` / `→` 同样用于切换图片。到第一张再按 `←`，或到最后一张再按 `→`，不会循环。
8. 「清空当前图框」只清空正在看的这张图，确认后生效。没有框时点它没有效果。
9. 不能从列表里删除某张已加入的图片。想从头再来，请刷新页面后重新打开文件。
10. 同名文件可以加入多次，它们是列表里的不同项，互不影响。导出时用文件名区分，不包含磁盘路径。

框不能拖动，也不能拉角改大小。位置不对时，删掉再画。

### 缩放、平移与快捷键

缩放范围是原图的 **5% 到 3200%**。工具栏上的百分比是四舍五入后的整数。

工具栏按钮在这些固定档位之间跳动，而不是任意比例：

5%、10%、15%、25%、33%、50%、67%、75%、100%、125%、150%、200%、250%、300%、400%、500%、600%、800%、1000%、1200%、1600%、2000%、2400%、3200%。

`+` / `−` 以当前视野中心为基准，跳到相邻档位。`Ctrl` 或 `Cmd` 加滚轮以鼠标光标下的位置为中心，每次约乘或除以 1.12，可以停在档位以外的比例上，但仍限制在 5%–3200%。滚轮指针需要在中间画布上。不按 `Ctrl` / `Cmd` 的滚轮只滚动中间画布，不改变比例。

- 「适应」把整张图缩进中间可视区域，四周留出约 24 像素边距，并且**最大不超过 100%**。小图不会被「适应」放大。按「适应」后滚动位置回到左上角。
- 「1:1」设为 100%，一个原图像素对应一个 CSS 像素，并尽量保持当前视野中心。
- 比例达到或超过 300% 时，图片使用像素化渲染；低于 300% 时由浏览器平滑缩放。这只影响看起来是否柔和，不影响导出数字。
- 改变浏览器窗口大小时，保持当前比例，并尽量保持视野中心，不会自动重新「适应」。

平移：

- 先按住空格，再在画布上按住左键拖动。开始拖动之后可以松开空格，直到松开鼠标才结束平移。
- 或者按住鼠标中键拖动，或先按住 `Alt` 再按住左键拖动。
- 平移通过滚动中间区域实现。图片若已经完整落在中间格子里，继续平移不会出现新的滚动，也不会画出框。
- 如果已经按下左键开始画框，此时再按住空格、`Alt` 或中键并移动，这次未完成的框会被取消，随后的移动只平移。

焦点在坐标系下拉框、文本框里时，空格留给控件本身，快捷键也不会去删框或切图。请先在画布或页面空白处点一下，再使用快捷键。

| 操作 | 如何触发 |
| --- | --- |
| 放大一档（视野中心） | 工具栏 `+`，或页面收到 `Ctrl`/`Cmd` 与 `+`/`=` |
| 缩小一档（视野中心） | 工具栏 `−`，或页面收到 `Ctrl`/`Cmd` 与 `-` |
| 以鼠标为中心缩放 | 指针在中间画布上时，`Ctrl`/`Cmd` + 滚轮 |
| 适应窗口（不超过 100%） | 工具栏「适应」，或页面收到 `Ctrl`/`Cmd`+`0` |
| 100% | 工具栏「1:1」，或页面收到 `Ctrl`/`Cmd`+`1` |
| 平移 | 空格拖动、中键拖动或 `Alt` 拖动 |
| 只滚动、不缩放 | 在中间画布上滚动鼠标滚轮 |
| 删除选中框；没选中则删除当前图最后一个框 | `Delete`、`Backspace`、「撤销框」或「删除选中框」。`Ctrl`/`Cmd`+`Z` 在页面收到按键时也是这个动作 |
| 上一张 / 下一张 | `←` / `→` |

Chrome 和 Edge 常常先拦截 `Ctrl+1`（切换标签）、`Ctrl+0`（重置浏览器自身缩放）以及 `Ctrl` 加加减号（浏览器缩放）。那些情况下页面收不到按键，本工具的比例不会变。请改用工具栏按钮，或使用 `Ctrl`+滚轮。`Backspace` 在这个页面里用来删框，不会当作浏览器后退。

「撤销框」和 `Ctrl`/`Cmd`+`Z` **不是**多步撤销。它们不会把刚删掉的框恢复回来，只会再删掉一个：有选中框就删选中框，否则删当前图最后一个框。

## 输入与输出

输入是本机的 JPEG、PNG、WebP 文件。页面只使用文件名和解码后的像素，不读取 EXIF 以外由浏览器自己决定是否应用的方向信息；坐标对应当前画面上看到的这张图，原点在画面左上角。本文不额外承诺某种 EXIF 旋转策略。

输出是浏览器下载的 `bboxes.json` 或 `bboxes.csv`。重复导出时，浏览器可能会把文件名加上 `(1)` 等后缀。页面不会把结果写回原图片。

### 坐标

坐标单位是**原图像素**，不是屏幕上的 CSS 像素，也不是缩放后的显示像素。

- 原点 `(0, 0)` 在图像左上角。
- `x` 向右增大，`y` 向下增大。
- 右边缘是 `x = width`，下边缘是 `y = height`。因此整张图的外框可以是 `x1 = 0, y1 = 0, x2 = width, y2 = height`。
- 这是图像平面上的边界坐标，不是「像素下标最大为 width - 1」的闭区间。`x2` 可以等于 `width`。
- 拖动时如果指针超出图片，会先夹到图片边缘，再换算。
- 换算结果四舍五入为整数。预览和导出里不会出现小数。
- 宽或高小于 2 的结果不保留。判断用的是原图像素：放得很大时，屏幕上要拖得比较远才够 2 个原图像素；缩得很小时，屏幕上短距离也可能足够。
- 图上色框的外沿对应该框的坐标（边框画在矩形内部）。边框只是显示，不会加进导出的宽高。
- 已有框的数字在缩放和平移前后保持不变。新画的框按松开鼠标时，指针相对于**当前显示中的图片**的位置换算回原图。

示意（不是某次导出）：

```text
(0,0) ---------- x 增大 ----------> (width, 0)
  |
  y 增大
  |
  v
(0, height)                         (width, height)
```

### xyxy 与 xywh

两种写法描述同一个矩形，原点、方向和单位相同。内部始终按左上角和右下角保存；导出时才按工具栏的选项转换。`x1 <= x2` 且 `y1 <= y2`。

下面这组数字是**说明用的例子**，不是程序自带样例，也不是某张真实照片的标注。

同一个框：

| 写法 | 含义 | 例子 |
| --- | --- | --- |
| `xyxy` | `x1,y1` 是左上角，`x2,y2` 是右下角 | `x1=10, y1=20, x2=110, y2=80` |
| `xywh` | `x,y` 是左上角，`w,h` 是宽和高 | `x=10, y=20, w=100, h=60` |

对应关系是 `x = x1`，`y = y1`，`w = x2 - x1`，`h = y2 - y1`。例子里宽是 `110 - 10 = 100`，高是 `80 - 20 = 60`。

切换坐标系会立刻改变右侧预览和之后的导出，不会改框在图上的位置。

### JSON

点「导出 JSON」得到 UTF-8、两个空格缩进的 `bboxes.json`，没有 BOM。字段如下：

| 字段 | 含义 |
| --- | --- |
| `coord_system` | 固定为 `original_image_pixels` |
| `format` | 导出当时工具栏的值：`xyxy` 或 `xywh` |
| `images` | 按加入顺序排列的图片数组 |
| `images[].image` | 文件名，不含路径 |
| `images[].width` / `height` | 解码后的像素宽高，正整数 |
| `images[].boxes` | 该图的框，按创建顺序。没有框时是空数组 |
| `xyxy` 的框 | `x1`,`y1`,`x2`,`y2`，整数 |
| `xywh` 的框 | `x`,`y`,`w`,`h`，整数，且 `w >= 2`、`h >= 2` |

导出里没有框的内部 id，也没有类别。右侧预览比完整文件少两层：没有 `coord_system` 和 `format`，只有当前图的 `image`、`width`、`height`、`boxes`。

**示例**（数字是编的）：

```json
{
  "coord_system": "original_image_pixels",
  "format": "xyxy",
  "images": [
    {
      "image": "a.jpg",
      "width": 320,
      "height": 240,
      "boxes": [
        { "x1": 10, "y1": 20, "x2": 110, "y2": 80 },
        { "x1": 140, "y1": 30, "x2": 200, "y2": 90 }
      ]
    },
    {
      "image": "b.jpg",
      "width": 480,
      "height": 360,
      "boxes": []
    }
  ]
}
```

同一批框在选择 `xywh` 时，第一张图的 `boxes` 会写成：

```json
[
  { "x": 10, "y": 20, "w": 100, "h": 60 },
  { "x": 140, "y": 30, "w": 60, "h": 60 }
]
```

这也是示例，不是运行结果。文件名里的中文按 UTF-8 原样写入，不会转成 `\uXXXX`。

### CSV

点「导出 CSV」得到 UTF-8 的 `bboxes.csv`，没有 BOM，换行是 `\n`。表头由坐标系决定：

```text
image,width,height,box_index,x1,y1,x2,y2
```

或

```text
image,width,height,box_index,x,y,w,h
```

- 每一行是一个框。`box_index` 从 1 开始，按**这一次导出时**该图剩余框的顺序编号。
- 删掉中间某个框再导出，后面的编号会前移。不要把 `box_index` 当成永久 ID。
- 文件名使用 JSON 字符串写入，因此普通文件名会带双引号，例如 `"a.jpg"`。文件名里的逗号因此不会把列拆开。
- 文件名里如果含有双引号或换行，转义方式是 JSON（`\"`），不是电子表格常用的双引号加倍。这种文件名请改用 JSON 导出。

没有框的图片仍占一行，框字段留空。**示例**：

```text
image,width,height,box_index,x1,y1,x2,y2
"a.jpg",320,240,1,10,20,110,80
"a.jpg",320,240,2,140,30,200,90
"b.jpg",480,360,,,,,
```

`xywh` 的示例：

```text
image,width,height,box_index,x,y,w,h
"a.jpg",320,240,1,10,20,100,60
"b.jpg",480,360,,,,,
```

上面两段都是说明格式用的例子。无框行在八列末尾是五个逗号：`box_index` 和四个坐标都空着。

### 多张图片且没有框

只要图片已经加入列表，即使一个框都没画，导出里也会有它：

- JSON：对应元素的 `boxes` 为 `[]`，`width` 和 `height` 为解码尺寸。
- CSV：该图一行，有文件名和宽高，没有序号和坐标。

还没在左侧点开过的图片也同样导出。不需要为了写宽高而逐张点开。

## 隐私

- 图片通过文件选择框或拖放进入当前页面的内存，用浏览器的 `blob:` 地址显示。
- 页面没有上传接口，没有统计，也没有外部脚本、字体或图片请求。标注过程不把图片或坐标发到网络。
- 导出由浏览器把文件下载到你自己的电脑，保存到哪里由浏览器的下载设置决定。
- 关闭页面后，内存里的图片数据会随页面一起丢掉。仓库和这个 HTML 文件都不会因此被改写。

## 限制

### 关闭、刷新与是否保存

所有图片和框都只存在于当前页面的内存中。

- 不使用 `localStorage`、`IndexedDB`、Cookie 或服务器保存。
- 刷新、关闭标签页、关闭浏览器窗口或崩溃之后，未导出的框和已打开的图片都会消失。
- 关闭前**没有**「尚未保存」的提示。
- 导出过的 JSON / CSV 是独立文件，之后在页面里改框不会更新已经下载的文件。需要新结果时请重新导出。
- 不能把导出文件再打开到这个工具里继续编辑。

### 其他限制

- 不能移动、缩放已有框，不能给框加类别或备注，不能从列表删除单张图片。
- 「撤销框」不能恢复被删掉的框。
- 「适应」不会超过 100%。
- GIF、SVG、BMP、TIFF 等不在接受范围内，选择后会被忽略。
- 图片很多或很大时，只受本机内存和浏览器解码能力限制，工具本身没有配额提示。
- CSV 无 BOM。用 Excel 直接双击打开时，中文文件名可能乱码；请用「自文本/CSV 导入」并选择 UTF-8，或改用 JSON。
- 本文说的快捷键是页面脚本的行为。浏览器或系统若先拦截该按键，页面不会执行对应动作。
- 若系统把 `Alt`+拖动或中键拖动占用成窗口操作或粘贴，平移可能无效。这时改用空格拖动。
- 无法解码的文件不会以宽高 0 写入导出；导出会被取消。
- 没有用户账号、协作或历史版本。

## 常见问题

**屏幕上量出的像素和导出不一致？**  
导出的是原图像素。图片被缩小时，屏幕上的一小段对应原图里的很多像素。请看右侧预览或导出文件，不要拿缩放后的屏幕距离直接当坐标。

**放大或平移之后，以前的框数字变了？**  
正常情况下不会变。若预览里的 `x1,y1,x2,y2` 变了，那是新画了一个框，或删过框。切换 `xywh` 只会改写法，例如宽变成 `x2 - x1`。

**刷新之后标注没了？**  
这是当前实现的限制，不是导出失败。请在刷新或关闭前下载 JSON 或 CSV。页面不会自动保存，也没有恢复入口。

**没画框的图、没点开的图会不会丢？**  
不会从导出里消失。没画框时 JSON 的 `boxes` 是空数组，CSV 仍有一行空坐标。没点开的正常图片也会带上真实宽高，而不是 0。

**导出提示尺寸未能读取？**  
该文件不是浏览器能解码的 JPEG、PNG 或 WebP，或文件已损坏。这次不会生成部分结果。请去掉该文件后重新导出。

**放大后左右栏被挤出屏幕？**  
当前版本把大图限制在中间格子内滚动，顶栏和左右栏应留在窗口里。若整页仍出现横向滚动，请刷新后再试一次；不要用浏览器自身的页面缩放（Chrome 的 `Ctrl+0` 常被用来重置它）来代替工具栏里的「适应」。

**平移时多出一个框？**  
空格、中键或 `Alt` 拖动不应留下框。若左键已经按下并开始画框，再按空格并移动，未完成的框会被取消。纯左键拖动仍会画框。

**画了但列表里没有？**  
框的宽或高小于 2 个原图像素时会被丢弃。把拖动拉长一些，或先放大再画。

**「适应」没有把小图放大？**  
「适应」的上限是 100%。要看原始大小请点「1:1」；要放更大请点 `+` 或使用 `Ctrl`+滚轮。

**能不能改框的大小，或把 JSON 导回来？**  
不能。请删除后重画。已导出的文件只能在外部使用，这个页面不能导入。

**按了 Ctrl+Z，框没有恢复，反而少了一个？**  
这是预期行为。「撤销框」和 `Ctrl`/`Cmd`+`Z` 只负责再删除一个框。

**Excel 里中文文件名是乱码？**  
CSV 是无 BOM 的 UTF-8。请在 Excel 中按 UTF-8 导入，或使用 JSON。
