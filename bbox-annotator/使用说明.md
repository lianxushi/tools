# 图片框选坐标工具

用浏览器打开同目录的 [`index.html`](index.html) 即可使用，不需要安装，也不需要联网。

功能、环境、安装与启动步骤、多图多框、缩放和平移、坐标约定、JSON / CSV、隐私、数据保存限制和常见问题，都写在 [README.md](README.md)。此处只保留入口；操作细节以 README 为准。

## 快速开始

1. 双击打开 `index.html`（或把该文件拖进 Chrome、Edge、Firefox、Safari）。
2. 点「打开图片」，或把 JPEG、PNG、WebP 拖进窗口。可以一次选多张。
3. 在图片上按住鼠标左键拖动画框。需要看清边缘时，用工具栏缩放；按住空格拖动可平移。
4. 选 `xyxy` 或 `xywh`，再点「导出 JSON」或「导出 CSV」。

导出的坐标是原图像素。刷新或关闭页面后，未导出的框会消失。
